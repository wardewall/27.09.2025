# Сервис фоновой загрузки файлов (2025-09-27)

Простой веб-сервис, принимающий задачи со списком URL для скачивания файлов. Задачи персистируются на диск и автоматически восстанавливаются после рестарта сервиса. Реализован graceful shutdown.

## Запуск

```bash
go run ./cmd
```

Переменные окружения:

- `APP_DATA_DIR` — путь к директории данных (по умолчанию `./data`)
- `APP_HTTP_ADDR` — адрес HTTP-сервера (по умолчанию `:9091`)

## HTTP API

- `POST /tasks`
  - Тело: `{ "urls": ["https://example.com/a", "https://.../b"] }`
  - Ответ: `202 Accepted` и JSON задачи

- `GET /tasks`
  - Список всех задач

- `GET /tasks/{id}`
  - Детали задачи, статусы и прогресс по каждому файлу

## Поведение при рестарте

- Задачи в состоянии `running` переводятся в `pending` при старте
- Очередь автоматически наполняется невыполненными задачами
- Промежуточное состояние задач сохраняется на диск атомарной записью

## Архитектура

- `internal/storage` — типы и файловое хранилище задач (JSON, atomic write)
- `internal/service` — менеджер очереди и воркеры скачивания (HTTP client, ретраи)
- `internal/api` — HTTP API (стандартная `net/http`)
- `cmd/main.go` — композиция компонентов, конфигурация и graceful shutdown

## Безопасность и надёжность

- Атомарная запись JSON через временный файл и `rename`
- Ограничение имени файла, санитизация путей
- Таймаут HTTP-запросов
- Ретраи задач на уровне менеджера (по умолчанию 2)
- Контекст отмены для graceful shutdown
